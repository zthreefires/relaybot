# /codex-setup

Load the `relaybot-setup` skill and follow it in this chat for both Codex and Claude Code. The same routine selection applies to either setup command. New bots use `relaybot-events`, and existing `codex-events` routines are reused as is. In a repository checkout, use the [canonical instructions](../relaybot-setup/SKILL.md). If those instructions are unavailable, ask the user to sync `relaybot-setup` alongside this alias.
